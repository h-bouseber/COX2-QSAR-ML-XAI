# COX2-QSAR-ML-XAI

Reproducible QSAR-XAI workflow for COX-2 inhibitor modeling.

## Workflow
1. NB1_Dataset_Curation.ipynb
2. NB2_Descriptor_Generation.ipynb
3. NB3_ML_Preparation.ipynb
4. NB4_QSAR_Modeling.ipynb

## Molecular representations
- PubChem fingerprints
- Morgan fingerprints
- RDKit descriptors

## Methods
- Random Forest
- Gradient Boosting
- SHAP analysis
- Molecular docking
- Applicability domain analysis

## Requirements
Python 3.10

## Repository associated with:
“Molecular Insights into Cyclooxygenase-2 Inhibitors Using Explainable Artificial Intelligence in Quantitative Structure–Activity Modeling”
